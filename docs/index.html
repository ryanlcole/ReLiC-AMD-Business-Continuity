Evidence labels

REPOSITORY FACT — directly inspectable in this repository.
PROJECT CANON — governing project rule. Canon status does not prove an external-world claim.
RECORDED HISTORY — a historical statement retained by the project but not independently proved by this repository.
VERIFIED RESULT — a result for which the repository identifies verification evidence.
PROPOSAL / HYPOTHESIS — not established as fact.
UNKNOWN — evidence is insufficient; no fact is inferred.

Truth rule

SOURCE → IDENTITY → TIME → PROVENANCE → CLAIM STATUS → VERIFICATION

If evidence supports only a project rule, it is labeled canon. If evidence supports only a historical project statement, it is labeled recorded history. If verification is absent, the page does not say verified. If the evidence is insufficient, the state is UNKNOWN.

ReLiC Share · repository facts, project canon, recorded history, verified results, proposals and unknowns remain distinguishable.
