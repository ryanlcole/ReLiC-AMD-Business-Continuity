The six duties

REMEMBER

Preserve errors, corrections, canon, authority/law records, success, known-working references, backups, provenance, decisions, and why changes occurred. History remains evidence rather than silently becoming current authority.

EXIST

Remain the continual reference boundary. Applicable authority, provenance, time, known errors, and current context are resolved before a dependent downstream action proceeds.

LIVE

Observe the current hackathon environment through interfaces that are actually authorized and connected. Historical state remains historical; current state must be established as current.

IMAGINE

Permit hypotheses, simulations, models, and fiction while keeping KNOWN, EVIDENCE, INFERENCE, HYPOTHESIS/FICTION, TEST, and RESULT distinguishable.

CREATE

Create a traceable report/context package retaining source, time, provenance, applicable authority, uncertainty/conflict, relevant errors/working references, test evidence, and result.

SHARE

Expose the hackathon implementation and proof to AMD: what exists, what governed it, what changed, what failed, what was verified, and what remains unknown or blocked.

Truth contract

REPOSITORY FACT — directly inspectable in this public repository.
PROJECT CANON — a governing ReLiC project rule; canon status does not prove an external-world claim.
VERIFIED RESULT — a result with identified verification evidence.
LEDGER RECORD — what the durable project record says happened; it is not silently upgraded into verification of the current commit.
PROPOSAL / HYPOTHESIS — not established as fact.
UNKNOWN — evidence is insufficient, so no fact is invented.

Truth path: SOURCE → IDENTITY → TIME → PROVENANCE → CLAIM STATUS → VERIFICATION.

Governing doctrine

1. Representation is not truth.
2. Identity is not output equivalence.
3. Evidence, interpretation, plan, execution, and result remain distinguishable.
4. Corrections remain evidence.
5. Errors become durable lessons.
6. Known-working code is evidence; a backup/reference is not automatically current canon.
7. Why must survive what.
8. Neurons organize; they do not legislate.
9. RuneCore structures meaning; it does not invent authority.
10. ReLiC is Environmental Intelligence and continuity infrastructure.

Authority resolution

Canon, rules, laws, and memorandums are authority-bearing record types. Their title alone does not determine precedence. The canon requires issuer/source, jurisdiction/scope, effective time, explicit precedence, amendment/correction/supersession relationships, applicability, and provenance to remain relevant to resolution.

Human-law boundary

Internal AI/project authority cannot authorize violation of applicable human law. The repository does not claim that its software independently determines all applicable law.

1 · Deterministic decision resolver — app/relic/engine.py

The resolver loads the synthetic policy corpus, produces a Decision with action/reason/evidence IDs/confidence, and deliberately remains deterministic before AMD model integration.

@dataclass(frozen=True)
class Decision:
    action: str
    reason: str
    evidence_ids: list[str]
    confidence: float

def evaluate_case(amount: float, customer_tier: str,
                  enterprise_plus_active: bool) -> Decision:
    policies = load_policies()
    evidence = [record["id"] for record in policies]

    if amount <= 500:
        return Decision("auto_approve",
            "The base policy requires manager approval only for refunds over $500.",
            ["POL-2026-01"], 1.0)

    is_active_plus = customer_tier.strip().casefold() == "enterprise plus" \
        and enterprise_plus_active
    if is_active_plus and amount <= 1000:
        return Decision(action="auto_approve", ... evidence_ids=evidence, confidence=1.0)

    return Decision(action="manager_approval", ... evidence_ids=evidence, confidence=1.0)

3 · Temporal continuity — app/relic/temporal.py

RatePeriod keeps valid time separate from recorded time. Superseded records are filtered without erasing them. Historical reconciliation calculates an Adjustment rather than rewriting the original WorkRecord.

    id: str
    person_id: str
    amount: str
    valid_from: str
    valid_to: str | None
    recorded_at: str
    source: str
    authority_id: str
    supersedes: str | None = None

def _active_records(records, known_at=None):
    known = _known_records(records, known_at)
    by_id = {record.id: record for record in known}
    superseded = {record.supersedes for record in by_id.values() if record.supersedes}
    return [record for record in by_id.values() if record.id not in superseded]

4 · RuneCore continuity inventory — app/relic/runecore.py

AuthorityRune represents a sourced authority-bearing record. The source itself warns that constructing a rune does not prove that the source is valid law/canon or applies to a real-world case.

AuthorityType = Literal[
 "human_law", "canon", "rule", "memorandum", "decision",
 "correction", "error", "working_reference", "plan"
]

@dataclass(frozen=True)
class AuthorityRune:
    id: str
    record_type: AuthorityType
    title: str
    source: str
    issuer: str
    scope: str
    effective_date: str
    status: str

def continuity_snapshot() -> dict:
    authorities = load_authority_runes()
    return {
      "authority_ids": [rune.id for rune in authorities],
      "authority_types": sorted({rune.record_type for rune in authorities}),
      "changes": len(load_change_history()),
      "working_references": len(load_working_references()),
      "neurons": len(load_neurons()),
      "human_law_boundary_present": any(
          rune.record_type == "human_law" for rune in authorities),
    }

def amd_chat(messages, timeout=30.0):
    config = get_amd_config()
    if config is None:
        raise RuntimeError("AMD vLLM endpoint is not configured")
    response = httpx.post(
        f"{config.base_url}/chat/completions",
        headers={"Authorization": f"Bearer {config.api_key}"},
        json={"model": config.model, "messages": messages, "temperature": 0},
        timeout=timeout,
    )
    response.raise_for_status()
    return response.json()
